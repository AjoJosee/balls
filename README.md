# Bouncing Balls 🎲

A fun canvas simulation of bouncing balls with interactive controls.

## Features

- **Physics**: Balls bounce off walls
- **Sliders**: Adjust number of balls, size, and speed
- **Responsive**: Works on any screen size

## Controls

| Control | Description |
|---|---|
| **Balls** slider | Changes number of balls (10‑100) |
| **Size** slider | Changes average ball size (5‑30) |
| **Speed** slider | Changes average ball speed (1‑15) |

## How to Play

1. Move the sliders to customize the simulation
2. Watch balls bounce around the canvas
3. Balls change color when they collide

Enjoy! ✨
